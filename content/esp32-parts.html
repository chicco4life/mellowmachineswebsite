The simplest public build

Start with one MicroTech MTR024QV01A-V1 CYD board, a USB data cable and a compatible Mac. Use the public Pixel character pack. Add a speaker only if you want audible sound effects; recorded speech requires a separate voice-capable pack.

Essential parts and tools

This list follows Buddygotchi’s firmware and character-pack documentation. It is a compatibility reference, not a priced bundle or a promise that any board sold as a CYD will work.

Start with USB power. A battery and a separate microphone are not required for the public Pixel walkthrough.

Check before ordering

  • Match the model and board revision, rather than the “CYD” nickname.
  • Check the display driver and touch controller against the firmware’s board configuration.
  • Use a data-capable USB cable; a charging-only cable cannot flash the board.
  • Choose a character pack that provides the face and sound features you want on your selected board.

We have not verified current retailer prices or stock. The firmware’s board configuration is the reference for pins and peripherals; consult it before substituting parts.
