# Mascot favicon

The project owner supplied the mascot illustration. The built-in image generation tool produced a transparent, square-framed icon source on 11 October 2026. The source is saved as `mascot-favicon.png` at 512 × 512 pixels; exports strip source image metadata.

Browser assets:

- `dist/favicon.ico`: 16, 32, 48 and 64 pixel variants.
- `dist/assets/favicon-mascot-32.png`: transparent 32 pixel PNG.
- `dist/assets/favicon-mascot-192.png`: transparent 192 pixel PNG.
- `dist/assets/apple-touch-icon-mascot.png`: opaque 180 pixel PNG with a white background.

The provided artwork remains subject to its original rights. This conversion does not establish a new license.

## Generation brief

Use case: background-extraction. Asset type: website favicon source. Edit target: the attached cream mascot illustration. Preserve the exact mascot identity, current pose, cream marshmallow-like cylindrical body, thick nearly black outlines, two dark oval eyes, arms, feet and existing shading. Change only the exterior white background to genuinely transparent alpha and frame the complete mascot tightly in a square canvas, centered, occupying about 90% of the width and height with a small clear margin. Keep the cream body solid and opaque. Do not redraw or redesign the character, add facial features, add text, add a circle or tile, or crop off limbs. This must remain recognizable as the exact supplied mascot when reduced to a small browser favicon.
